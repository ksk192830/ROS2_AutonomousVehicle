# Enhancing Perpendicular Parking in a ROS2 Autonomous Driving Framework

**부제:** A State-Based Multi-Sensor Approach

**분류:** ASK 2026 · **논문경진대회 동상** · [상장](../../docs/awards/kips-bronze.pdf)

**주요 내용:** 기존 LiDAR 중심 주차 알고리즘을 개선하여 전·후방 카메라의 YOLO11n-seg 결과, Bird's-Eye View 변환 및 2D LiDAR 기반 빈 공간 탐색을 결합합니다. 탐색·후진 진입·자세 보정·탈출 단계를 상태 기반으로 관리하며, 상태에 따라 필요한 인지 노드만 활성화해 계산 부하를 줄입니다.

**연구의 한계:** 조명 변화에 따른 후방 인지 오류와 LiDAR 탐색 실패, 조향 한계 등 실패 조건도 분석했습니다.
