# 재현 준비 검증 기록

확인일: 2026-10-30 (한국 시간)

코드 리비전 `07c1f79`의 [GitHub Actions 검사](https://github.com/ksk192830/ROS2_AutonomousVehicle/actions/runs/40926303722)가 성공했습니다. 이후 도구·테스트 경로를 `tools/`로 정리한 리비전 `0c3e45d`에서도 [문법·회귀 검사와 두 프로젝트 빌드·launch 로딩 검사](https://github.com/ksk192830/ROS2_AutonomousVehicle/actions/runs/40970004586)가 통과했습니다. 아래 표는 해당 검사와 별도로 수행한 로컬 자산 점검의 범위를 구분해 기록합니다.

| 검사 | 결과 | 범위 |
| --- | --- | --- |
| Python 및 Bash 문법 | 통과 | 제4회·시뮬레이션 및 보조 스크립트 |
| 복구·점검·경로 로더 회귀 테스트 | 5개 통과 | LFS 포인터, 누락 텍스처, 모델 종류, 기존 파일 보호, 임의 위치 설치 경로 |
| 제4회 ROS 빌드 | 통과 | Ubuntu 22.04 / ROS 2 Humble, 독립 7개 패키지 |
| 시뮬레이션 ROS 빌드 | 통과 | 동일 환경, 독립 9개 패키지 및 Gazebo C++ 플러그인 |
| 설치된 launch 인자 로딩 | 6개 통과 | 각 프로젝트의 general_sim / mission_sim / parking_sim, `--show-args` |
| 로컬 자산 파일 점검 | 6개 통과 | 원본 자산을 복구한 로컬 작업 사본, 각 3개 시나리오 |

CI는 공개 소스만 사용합니다. 로컬 자산 검사에서 사용한 비공개 바이너리를 CI에 업로드하지 않았습니다. 따라서 CI 빌드 성공만으로 새 clone의 자산이 준비됐다고 판단할 수 없습니다. [복구 및 실행 안내](reproduction.md)를 별도로 따릅니다.

## 아직 수행하지 않은 검증

- 실제 모델 추론, TensorRT 엔진 생성·호환성 확인
- Gazebo 센서 스트림 및 차량 구동, 미션 성공 여부, 물리·성능 지표
- 전시 GUI 상호작용 전체 흐름 및 실차 장치·주행
- 제3회와 경기도 프로젝트의 ROS 빌드

이 기록은 재현 준비와 설치 구성을 확인한 결과이며, 주행 성능을 검증한 결과가 아닙니다. 제4회 실차 엔진은 대상 GPU에서 별도로 준비합니다. 다른 경량화 연구 저장소와의 자동 연동은 포함하지 않습니다.
